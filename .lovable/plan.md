# Floral memorial background and tribute page

## Overview
Add tasteful floral artwork behind the existing memorial design, then create a new public Tributes page whose heading, introduction, and tribute entries are managed from the protected editor.

## Changes
- Create a subtle transparent floral illustration that complements the ivory, green, and antique-gold palette.
- Place the floral artwork as low-contrast corner accents across public pages without reducing readability or affecting the editor.
- Add a **Tributes** item to desktop navigation, mobile navigation, and the footer.
- Create `/tributes` with a memorial introduction and a responsive collection of tribute entries.
- Add a dedicated **Tributes** section in the editor.
- Let the owner add, remove, reorder, and edit each tribute’s author, relationship, message, and date.
- Add Tributes to the supported content keys and the secure save validation, using the existing protected content workflow.
- Seed sensible starter copy in code so the page has a polished empty/default state while remaining fully editable.
